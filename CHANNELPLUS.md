# Channel +

Android TV fork of OwnTV and OwnTV Core by ahXN00 and contributors, distributed under GPLv3. Original licences remain in owntv_tdt/LICENSE and owntv_core_tdt/LICENSE; bundled fonts retain their OFL notices.

The app builds with the local core source, including the existing TDT bridge. Package tv.own.owntv.tdt2 and stored icon choices are retained. Branding assets are generated by tools/channelplus/render_brand.py using the bundled OFL Poppins font.

## Updates

The app checks public releases in Ayanawars/Channelplus. Publish a numerically newer version tag (next build: v5.2.2, versionCode 100001) with an ARM .apk asset; x86 builds must include x86_64 in the filename. Android asks before installing. Existing installed versions need the first Channel + APK installed manually, because their updater is disabled.

An upgrade must use the original signing key, retained outside Git. Never commit a keystore. CI generates a disposable key, so its artifacts cannot update the existing TV installation. Production releases must use KEYSTORE_FILE, KEYSTORE_PASSWORD, KEY_ALIAS and KEY_PASSWORD via private build inputs. Do not publish a CI APK as an update.

## Validation

Resource XML parsing and the application's hardcoded-string check pass locally. Full Gradle build is blocked locally by network access to services.gradle.org. The GitHub workflow performs unit tests and assembles a debug APK; its result must be inspected before claiming a build passed. Playback, tuner, IPTV groups, and update installation still require verification on the TV with Bugjaeger.
