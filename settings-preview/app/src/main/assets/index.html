STAYON+ · Árbol de configuración

Editor independiente · Funciona sin conexión
Guardado automáticamente en este navegador

Pasa el S Pen o el ratón por encima de cualquier opción para ver su explicación; también puedes pulsar ⓘ para leerla. Usa ✎ para renombrar, + para añadir submenús, ↑ ↓ para ordenar y ↳ para trasladar un menú a otra sección. Los cambios se guardan en este navegador; exporta JSON para conservarlos y seguir editando en otro dispositivo. La base reproduce el árbol 5.4.11 que has facilitado; no es una extracción verificada de la APK.

⠿ Mantén pulsado este símbolo y arrastra con el S Pen, el dedo o el ratón para cambiar el orden. Suelta en el centro de un menú para introducirlo como submenú; en los bordes para colocarlo antes o después. También puedes sacarlo a otra sección.
