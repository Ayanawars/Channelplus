# Channel+

Aplicación Android TV basada en OwnTV 5.2.1 y OwnTV Core 1.0.69, con integración del sintonizador TDT de TCL y fuentes IPTV.

Se conservan las licencias GPL y atribuciones de los proyectos originales. La clave de firma no se incluye en el repositorio.

Importación inicial del código en curso.
